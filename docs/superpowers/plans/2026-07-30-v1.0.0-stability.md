# AWS Cost Exporter v1.0.0 Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stabilize the v0.3 exporter as v1.0.0 with machine-checked public contracts, deterministic single-replica lifecycle behavior, documented security and SemVer policies, and reproducible capacity and supply-chain evidence.

**Architecture:** Preserve background collection, immutable snapshots, atomic publication, and AWS-free scrapes. Add versioned fixtures beside the configuration, metrics, and HTTP owners; add a shutdown readiness gate; enforce non-overlapping Helm upgrades; and keep long-running performance validation outside normal PR CI.

**Tech Stack:** Go 1.24+, Prometheus client_golang, AWS SDK for Go v2, `net/http`, Helm 3, GitHub Actions, GoReleaser, Trivy, Syft, cosign, promtool, and kubeconform.
