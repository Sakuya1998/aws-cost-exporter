# v1.0.0 Release Checklist

This checklist is the release-candidate gate. Check an item only after attaching
sanitized, reproducible evidence. Do not record account IDs, credentials, cost
values, SQL, AWS responses, rendered Secrets, or speculative digests here.

## Public contracts and code quality

- [ ] Review the v1 configuration, Prometheus, HTTP, and release contract diff.
- [ ] Confirm repository coverage is at least 79% and core coverage is at least 85%.
- [ ] Run full tests, race tests on Linux, `go vet`, gofmt, and golangci-lint v2.12.2.
- [ ] Validate delivery assets: Helm, dashboard, rules, docs, CI, release, and contract suites.
- [ ] Run the Linux container smoke and multi-architecture checks.

## Capacity and AWS behavior

- [ ] Confirm the 20-target, 20,000+ business-series capacity gate remains below 5 seconds.
- [ ] Complete the manual 24-hour stability workflow with at least 99.9% scrape success and no sustained resource growth.
- [ ] Complete sanitized real AWS validation using capability-specific least privilege policies.
- [ ] Record bounded request/page counts and error categories without billing or account data.

## Security and supply chain

- [ ] Run gitleaks, govulncheck, gosec, Trivy, and dependency review; document each vulnerability disposition.
- [ ] Confirm six archives, six SPDX archive SBOM files, and `checksums.txt` in the Draft Release.
- [ ] Confirm Buildx provenance and SBOM attestations for Linux amd64 and arm64 images.
- [ ] Confirm the Helm OCI chart package, image manifest, and immutable digests.
- [ ] Run independent `cosign verify` for the image and chart using the recorded workflow identity and issuer.
- [ ] Download and validate the sanitized `release-audit-input` workflow artifact.

## Upgrade and publication

- [ ] Validate the v0.3.0 to v1.0.0 Helm upgrade, expected temporary outage, no pod overlap, and rollback.
- [ ] Confirm the GitHub Release remains a Draft Release until all evidence is reviewed.
- [ ] Publish only after the immutable v1.0.0 verification record contains actual workflow URLs, source commit, asset count, digests, and cosign policy.

The 24-hour stability, real AWS, upgrade/rollback, and final release evidence are
external release gates. Normal PR CI does not claim or substitute for them.
