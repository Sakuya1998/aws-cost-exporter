# v1.0.0 Release Checklist

This checklist is the release-candidate gate. Check an item only after attaching
sanitized, reproducible evidence. Do not record account IDs, credentials, cost
values, SQL, AWS responses, rendered Secrets, or speculative digests here.

- [x] Review the v1 configuration, Prometheus, HTTP, and release contract diff.
- [x] Confirm repository coverage is at least 79% and core coverage is at least 85%.
- [x] Run full tests, race tests on Linux, `go vet`, gofmt, and golangci-lint v2.12.2.

## Upgrade and publication

- [ ] Validate the v0.3.0 to v1.0.0 Helm upgrade, expected temporary outage, no pod overlap, and rollback. Explicitly deferred by the maintainer for v1.0.0; not reported as passed.
- [x] Confirm the GitHub Release remains a Draft Release until all evidence is reviewed.
- [ ] Publish only after the immutable v1.0.0 verification record contains actual workflow URLs, source commit, asset count, digests, and cosign policy.

The 24-hour stability, real AWS, upgrade/rollback, and final release evidence are
external release gates. Normal PR CI does not claim or substitute for them.

For v1.0.0, the 24-hour stability, real AWS, request/page observation, and
upgrade/rollback gates were explicitly deferred by the maintainer. Their
unchecked state is intentional and must not be interpreted as successful
validation. Completed artifact and supply-chain evidence is recorded in
[`v1.0.0-verification.md`](v1.0.0-verification.md).
